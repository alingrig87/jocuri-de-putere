# Puteri în Joacă

Un joc educativ pentru copii, creat în limba română, pentru a învăța calculul cu puteri pas cu pas, de la niveluri simple până la provocări mai complexe.

## Ce conține jocul

- 5 niveluri progresive
- întrebări generate aleatoriu
- ponturi și stare de progres
- explicații după fiecare răspuns
- reguli de bază și trucuri pentru memorare
- animații și design prietenos pentru copii
- salvare locală în browser pentru progres

## Cum se rulează local

Deschide fișierul `index.html` în browserul preferat. Nu ai nevoie de instalări sau dependințe.

## Publicare pe GitHub Pages

În repository există și un workflow gata pregătit pentru GitHub Pages:

- `.github/workflows/pages.yml`

După ce repo-ul este accesibil pentru deploy, poți activa publicarea din:

- Settings → Pages → Source: GitHub Actions

Dacă repo-ul este privat, GitHub Pages poate necesita planul adecvat și setări specifice. Pentru un site accesibil public, depozitul va trebui să fie public sau să respecte politica planului GitHub al contului.
